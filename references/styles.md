# Styles：5 套视觉风格

风格 = 色板 + 字体 + 背景 + 面板/圆角/发光 + 动效手感。`templates/styles/<name>.json` 是唯一事实来源；`init_project.py` 会把它复制成 `build/theme.js`。

选型：
- 芯片/电路/数据/工程 → `silicon` 或 `blueprint`
- 人文/生物/历史/讲义 → `paper`
- 发布/营销/年轻化/音乐 → `neon`
- 数据/编辑/极简/严肃 → `swiss`

---

## silicon（硅片剖面）
- **背景**：深空蓝黑渐变 + 电路走线 + 缓慢脉冲粒子 + 暗角。
- **色板**：`#04060c → #081120`；电青 `#3fe7ff`；琥珀 `#ffb454`；品红 `#ff4f8b`；绿 `#5df2a6`；正文 `#eaf4ff`；灰 `#8fa6c4`。
- **字体**：标题/正文 微软雅黑；位/编号 Consolas。
- **面板**：深色半透明 + 细描边 + 轻微 glow；圆角 16–20。
- **动效**：fast-out；镜头轻微推进；扫光转场。
- **适合**：计算机组成、芯片、网络、算法、工程拆解。

## paper（纸本讲义）
- **背景**：暖白纸纤维 + 极淡横线 + 手绘感边缘；可加少量墨点。
- **色板**：纸 `#f6f1e6`；墨 `#26211a`；朱砂 `#c2410c`；松绿 `#1f6f5c`；胭脂 `#b23a48`。
- **字体**：标题宋体/思源宋体；正文 微软雅黑；公式 Cambria Math/Consolas。
- **面板**：无填充或纸色填充，细墨线，几乎无发光；圆角 6–10。
- **动效**：像笔尖划过；元素“画出来”而不是“弹出来”；转场用纸张推移。
- **适合**：人文、生物、医学、历史、讲义、考试复盘。

## blueprint（蓝图）
- **背景**：深蓝底 + 白色细网格 + 角标 + 尺寸线。
- **色板**：`#06182e`；白 `#e8f2ff`；青 `#66d9ff`；黄 `#ffd166`；红 `#ff6b6b`。
- **字体**：标题 等宽/工程字；正文 微软雅黑；编号 Consolas。
- **面板**：透明 + 1px 白线 + 虚线；圆角 0。
- **动效**：线条生长、尺寸标注依次出现、镜头平移。
- **适合**：机械、建筑、电子、系统架构、流程。

## neon（霓虹）
- **背景**：深紫黑 + 网格地平线 + 光晕 + 粒子。
- **色板**：`#0a0414`；品红 `#ff3df2`；青 `#3df2ff`；柠檬 `#d4ff3d`；白 `#f4ecff`。
- **字体**：粗黑体；英文用几何无衬线。
- **面板**：高亮描边 + 较强 glow；圆角 12–24。
- **动效**：快、弹、节奏强；卡点；适合配电子/流行音乐。
- **适合**：发布、营销、音乐、游戏、年轻化内容。

## swiss（瑞士网格）
- **背景**：纸白 + 12 列网格 + 大量留白。
- **色板**：白 `#f4f3ef`；黑 `#111`；红 `#e03c31`；灰 `#8a8a86`。
- **字体**：Helvetica/Arial/Inter；标题粗，正文常规。
- **面板**：无圆角、无阴影、1px 黑线或纯色块。
- **动效**：克制；位移/遮罩/数字滚动；不做发光。
- **适合**：数据、编辑、严肃科普、品牌极简。

## 自定义风格

复制一份 JSON，至少改：
```json
{
  "name": "my-style",
  "bg": ["#....", "#...."],
  "colors": { "accent": "...", "accent2": "...", "accent3": "...", "text": "...", "muted": "...", "panel": "..." },
  "font": { "title": "...", "body": "...", "mono": "..." },
  "background": "circuit|paper|grid|nebula|swiss",
  "panel": { "radius": 16, "fillAlpha": 0.6, "strokeAlpha": 0.4, "glow": 12 },
  "motion": { "speed": 1.0 }
}
```
背景类型在 `lib.js` 的 `drawBackground` 里扩展；没有的先用 `grid` 兜底。

**避免的默认审美**：深色背景 + 居中大字 + 所有元素淡入淡出 + 满屏渐变。选风格后，至少让“背景/版式/运动”三者中有两样明显不同。
