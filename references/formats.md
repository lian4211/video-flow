# Formats：画幅、安全区与竖屏重排

## 1. 画幅表

| 名称 | 尺寸 | 典型平台 | 默认 fps |
|---|---|---|---|
| `16:9` | 1920×1080 | B 站、YouTube、课堂 | 30 |
| `9:16` | 1080×1920 | 抖音、小红书、Shorts、Reels | 30 |
| `1:1` | 1080×1080 | 小红书/Instagram 方图视频 | 30 |
| `4:5` | 1080×1350 | Instagram feed | 30 |

渲染时 `canvas` 必须等于目标尺寸，不要渲染大图再裁（会改变字号/构图）。

## 2. 安全区

- 16:9：左右 96 px，上下 64 px；底部进度条 40 px 以内不要放正文。
- 9:16：左右 64 px，上下 160 px（避开平台 UI）；底部 220 px 不要放关键信息。
- 1:1：四周 72 px。
- 4:5：四周 80 px。

字幕位置：
- 横屏：底部 72–120 px，居中，最多两行；
- 竖屏：底部 260–340 px（避开平台按钮），字号 34–42。

## 3. 版式重排（竖屏不是裁剪）

| 横屏 | 竖屏 |
|---|---|
| 左文右图 | 上文下图（标题→图→结论） |
| 三栏对比 | 上下堆叠或“左右窄栏 + 中间图” |
| 横向流程 4 步 | 纵向流程 4 步，箭头向下 |
| 大段正文 | 拆成 2–3 屏 |
| 一行 22 字 | 一行 ≤ 14 字 |

模板的 `layout()` 返回：
```js
{ W, H, portrait, contentX, contentW, top, bottom, titleSize, bodySize, cols }
```
场景函数一律用它，不要写死 1920/1080。

## 4. 字号与行高

| 元素 | 16:9 | 9:16 |
|---|---|---|
| 主标题 | 72–120 | 64–96 |
| 副标题 | 28–40 | 32–44 |
| 正文 | 26–36 | 32–42 |
| 标签/注释 | 18–22 | 22–28 |
| 数字/公式 | 64–140 | 56–120 |

行高 1.35–1.55；中文标题字重 700–800，正文 400–500。

## 5. 字幕文件

SRT 用 UTF-8；每条 ≤ 22 个中文字符（竖屏 ≤ 14），时长 1.2–6 s；不要跨镜头。
`scripts/srt.py` 会按 `voStart/voDur` 与标点自动切分；最终由 `encode.py --srt` 内封。

## 6. 多画幅输出

同一个 `script.json`：
```bash
python scripts/init_project.py --dir cut-916 --format 9:16 --style paper --script ../my-video/script.json
```
复制项目后只改 `project.json.format`，重新 `render.py`；`layout()` 会自动适配。
注意：竖屏下文字更长，可能需要把某些 `headline` 缩短，单独维护 `script-916.json` 也可以。
