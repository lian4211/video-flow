# Formats：画幅、安全区与竖屏重排

## 1. 画幅表

| 名称 | 尺寸 | 典型平台 | 默认 fps |
|---|---|---|---|
| `16:9` | 1920×1080 | B 站、YouTube、课堂 | 30 |
| `9:16` | 1080×1920 | 抖音、小红书、Shorts、Reels | 30 |
| `1:1` | 1080×1080 | 小红书/Instagram 方图视频 | 30 |
| `4:5` | 1080×1350 | Instagram feed | 30 |

渲染时 `canvas` 必须等于目标尺寸，不要渲染大图再裁（会改变字号/构图）。

## 2. 安全区

- 16:9：左右 96 px，上下 64 px；底部阶段条 40 px 以内不要放正文。
- 9:16：左右 54 px，上下 120 px；正文区到 y≈1560，**字幕区 1560–1730**，**阶段条 1738–1888**。底部 220 px 不要放关键信息。
- 1:1：四周 72 px。
- 4:5：四周 80 px。

字幕位置：
- 横屏：底部 72–120 px，居中，最多两行；硬字幕 `MarginV≈64`，字号 42–46。
- 竖屏：底部 250–300 px（避开平台按钮），字号 42–46；硬字幕 `MarginV≈250`。
- 字幕底边与阶段条/答案卡至少留 16 px。

## 3. 版式重排（竖屏不是裁剪）

| 横屏 | 竖屏 |
|---|---|
| 左文右图 | 上文下图（标题→图→结论） |
| 三栏对比 | 上下堆叠或“左右窄栏 + 中间图” |
| 横向流程 4 步 | 纵向流程 4 步，箭头向下 |
| 大段正文 | 拆成 2–3 屏 |
| 一行 22 字 | 一行 ≤ 14 字 |

简单模板的 `layout()` 返回：
```js
{ W, H, portrait, contentX, contentW, top, bottom, titleSize, bodySize, cols }
```
**`layout()` 只适合简单卡片式模板**。讲解片包含公式、例题步骤、答案卡、阶段条时，不要只靠它压缩；复制工程、单独写竖屏/横屏 `app.js`，每个场景按手机阅读顺序重排（标题→题目→步骤→结论）。实测 9:16 的 `formats` 参数见 `references/mobile-video.md`。

## 4. 字号与行高

| 元素 | 16:9 | 9:16 |
|---|---|---|
| 主标题 | 72–120 | 64–96 |
| 副标题 | 28–40 | 32–44 |
| 正文 | 26–36 | 30–40（手机 ≥28） |
| 标签/注释 | 18–22 | 22–28 |
| 数字/公式 | 64–140 | 56–120 |

行高 1.35–1.55；中文标题字重 700–800，正文 400–500。

## 5. 字幕文件

SRT 用 UTF-8；每条 ≤ 22 个中文字符（竖屏 ≤ 14），时长 1.2–6 s；不要跨镜头。
竖屏中英混排时用“可视宽度”换行：中文 1.0、拉丁 0.55、空格 0.35；保留空格，避免 `$\int$` 之类公式被切断。
`scripts/srt.py` 会按 `voStart/voDur` 与标点自动切分。

字幕两种交付：
- 软字幕：`encode.py --srt out/final.srt`（会内封 mov_text）；
- 硬字幕：`make_ass.py` → `encode.py --ass out/final.ass`（手机平台必用，`PlayResX/Y` 必须等于画布）。

## 6. 多画幅输出

同一个 `script.json`：
```bash
python scripts/init_project.py --dir cut-916 --format 9:16 --style paper --script ../my-video/script.json
```
复制项目后只改 `project.json.format`，简单模板可由 `layout()` 适配；讲解片建议直接复制整套工程并重写布局。
注意：竖屏下文字更长，需要把 `headline` 缩短、把长句拆屏；单独维护 `script-916.json` 也可以。横竖屏互转时，优先复用同一套配音/时间轴/字幕，避免重新 TTS。
